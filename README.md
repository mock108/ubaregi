# ウバレジ

Uber Eatsの配達で現金を受け取るときに使う、個人向けのAndroid補助アプリです。
商品金額と受取金額からおつりを計算し、レジの現金と受渡し履歴を端末内で管理できます。

> ウバレジはUberまたはUber Eatsの公式アプリではありません。

## できること

- 商品金額と受取金額から、おつりまたは不足額を計算
- 初期釣銭を登録してレジを開始
- 釣銭の補充、現金の取出しを記録
- レジ締め時の実残高、次回釣銭、過不足を確認
- レジごとの受渡し履歴を確認
- 保存した履歴の編集、取消し
- インターネット接続なしで計算・記録・履歴確認

## 使い方

### おつりを計算する

1. 「計算」を開きます。
2. 商品金額とお客様の受取金額を入力します。
3. 表示されたおつり、または不足額を確認します。
4. 実際に現金を受け渡した後、「受渡しを記録」を押します。

レジを開始していなくても、計算だけ利用できます。記録を残す場合は、先に「レジ」からレジを開始してください。

### レジを管理する

1. 「レジ」を開き、初期釣銭を入力してレジを開始します。
2. 必要に応じて「釣銭補充」または「現金取出し」を記録します。
3. 配達を終えるときは、実際の手元現金と次回釣銭を入力します。
4. 過不足と取出額を確認して、レジを締めます。

締めたレジは履歴として残り、あとから内容を確認・修正できます。締め済みレジには新しい受渡しを追加できません。

### 履歴を確認する

「計算」画面の「記録」タブから、選択中のレジの受渡し履歴を確認できます。レジの選択を変えると、そのレジの履歴が表示されます。

## データの扱い

- ログインは必要ありません。
- 業務データは端末内に保存します。
- クラウド保存、複数端末との同期、広告、アクセス解析は行いません。
- Uber、会計ソフト、外部サービスへ業務データを自動送信しません。
- 問い合わせを選んだ場合だけ、外部ブラウザーでGitHub Issuesを開きます。

アプリのアンインストール、アプリデータの消去、端末の故障などにより、端末内の履歴は失われます。必要な記録は利用者自身で管理してください。アプリには自動バックアップや、出力ファイルからの復元機能はありません。

## 注意事項

- 表示される現金回収額は、Uber Eatsの報酬や利益を示すものではありません。
- Uber Eatsの注文情報、配達情報、顧客情報とは連携しません。
- 個人利用・1台の端末での利用を前提としています。
- GitHub Issuesは公開ページです。問い合わせの際は、実際の顧客情報や配達記録を記載しないでください。
