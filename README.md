# ウバレジ

Uber Eatsの配達で扱う現金とおつりを記録する、Android向けの非公式補助アプリです。開発者は **Mockup** です。

## 現在の状態

段階3（開始・おつり計算・現金記録・レジ締め・履歴編集／取消・全履歴クリア）まで実装済みです。JDK 17、Gradle Wrapper 9.5.0、Android API 37 / Build Tools 36.0.0で個人用debug APKをビルドできます。端末またはエミュレーターでの画面確認は未実施です。

現在はホーム、レジ締め / 初期釣銭、おつり計算、アプリ情報の4画面で、Roomへの保存、再起動後の保持、受渡し・補充・取出し、レジ締め、履歴の編集・取消・全履歴クリアまで利用できます。CSV / JSON出力は段階4で実装します。

**アプリ開発 → 個人運用 → 問題がなければGoogle Play公開**の順で進めます。公開日を先に決めず、当面は個人用APKで確認します。Google Playの開発者登録、公開用署名鍵の作成、購入商品の登録は後日行います。

## 段階1〜3で確認できること

- ホームから4画面を移動し、戻る操作でホームへ戻る。
- アプリ情報でMockup、個人用版、実際のバージョン、対応OS、個人用の説明を確認する。
- 同梱プライバシーポリシーとOSS表示・ライセンス全文をアプリ内で展開する。
- GitHub Issuesを本人の操作で外部ブラウザーに開く。業務データはURLへ付加しない。
- 初期釣銭、受渡し、補充・取出し、実残高、次回釣銭を入力してレジを締める。
- アプリを開き直した後も、レジと明細が端末内に残る。
- 締め済みレジの既存履歴を編集・取消し、取消済みは元金額を残して集計から除外する。
- 全履歴クリアで稼働中を含む業務履歴を消去する。

## 今後の主な機能

- 帳簿加工用の独自CSV / JSON出力。

計算・記録・履歴・締め・ローカルへの出力はオフラインで行います。ログイン、広告、解析、クラウド同期は設けません。個人用では課金機能を無効にし、問い合わせ時だけ外部ブラウザーでGitHubを開きます。

将来の公開版も全機能無料とし、任意の開発支援購入を用意する予定です。現金回収額は配達報酬・利益を意味しません。Uberとの連携や会計ソフトへの直接記帳は行いません。

## 決定した設定

| 項目 | 値 |
| --- | --- |
| 開発者 | Mockup |
| 対象 | Android 17 / API 37、日本語、日本円 |
| 公開版のアプリID | `io.github.mock108.ubaregi` |
| 個人用のアプリID | `io.github.mock108.ubaregi.debug` |
| 初期アプリ版 | `0.1.0` / `versionCode = 1` |
| 構成 | Kotlin、Compose、Room、単一アプリモジュール、4画面 |
| ライセンス | MIT |

アプリID等は実装に使う確定値であり、Google Playへの登録済みを意味しません。個人用と公開版は別アプリとして併存させ、データの自動移行は行いません。初期版のCSV / JSONにはアプリへの再取込機能がないため、個人運用記録は出力ファイルと個人用アプリで保持します。

## 開発・問い合わせ

変更は公開ブランチで管理します。小さな文書修正は`main`、アプリ実装は`feature/<内容>`等の作業ブランチからPull Requestで取り込みます。自動配布・自動公開は設けません。

[GitHub Issues](https://github.com/mock108/ubaregi/issues)で不具合や改善案を受け付けます。公開Issueには顧客情報や実際の配達記録を載せず、架空の金額で再現方法を書いてください。

公開用の設定見本は[release.properties.example](release.properties.example)です。実際の鍵・パスワード・個人の記録はGitに登録しません。`.gitignore`は取り違えを減らす補助であり、コミット前には差分も確認します。
